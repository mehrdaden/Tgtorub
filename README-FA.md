# tg2rub v2 — ربات تلگرام ← روبیکا

فایل را به ربات تلگرام بفرست یا لینک صفحه/فایل را ارسال کن؛ با دکمه‌ها نام، ZIP (با رمز AES-256 اختیاری)، تقسیم به N قسمت را تنظیم کن و به
Saved Messages روبیکا آپلود کن. درصد پیشرفت دانلود نمایش داده می‌شود و بعد از آپلود فایل از سرور پاک می‌شود.

## تفاوت با نسخه قبل
- **بدون کامپایل و بدون سرور Bot API**: ربات با MTProto (Telethon) کار می‌کند؛ نصب فقط چند دقیقه پیپ است.
- **دانلود موازی** از تلگرام (سریع‌تر).
- **دانلود لینک با yt-dlp** برای سایت‌های پشتیبانی‌شده، لینک مستقیم HTTP/HTTPS و بسیاری از سرویس‌های ویدئویی؛ هر لینک الزاماً قابل دانلود نیست و بعضی سایت‌ها به ورود/کوکی نیاز دارند.
- **تا ۱۰ بار تلاش خودکار برای آپلود** با تغییر روش: نام اصلی ← نام ASCII ← پسوند `.bin` ← داخل ZIP.
- ربات هنگام آپلود/دانلود قفل نمی‌شود، دکمه «⛔ لغو» دارد و اگر تلگرام قطع شود خودش ری‌استارت می‌شود.
- `/diag` آخرین خطاها را نشان می‌دهد؛ `diag.py` اتصال تلگرام را روی سرور تست می‌کند.

## نصب کنترل‌شده (Ubuntu 22.04 یا 24.04)
    sudo apt update
    sudo apt install -y unzip python3 python3-venv python3-pip ca-certificates
    unzip tg2rub-v2-fixed.zip
    cd tg2rub
    sudo SKIP_LOGIN=1 bash install.sh

پس از نصب، ورود روبیکا را جداگانه انجام بده:
    sudo -u tg2rub /opt/tg2rub/app/venv/bin/python /opt/tg2rub/app/login_rubika.py

سپس در حالی که سرویس هنوز اجرا نشده، ارتباط تلگرام را تست کن:
    sudo -u tg2rub /opt/tg2rub/app/venv/bin/python /opt/tg2rub/app/diag.py

اگر تست MTProto موفق بود، سرویس را فعال کن:
    sudo systemctl enable --now tg2rub

## تنظیمات
`/opt/tg2rub/app/.env` (بعد از تغییر: `sudo systemctl restart tg2rub`). نمونه همه گزینه‌ها: `env.example`

## عیب‌یابی
- لاگ: `journalctl -u tg2rub -f`
- سشن روبیکا را بی‌دلیل پاک نکن؛ حذف آن باعث نیاز به ورود مجدد می‌شود.
- نسخه rubpy ناسازگار بود: `sudo -u tg2rub /opt/tg2rub/app/venv/bin/pip install rubpy==7.0.4 && sudo systemctl restart tg2rub`
- حذف کامل: `sudo bash uninstall.sh`


## دانلود لینک
یک URL با `https://` در گفتگوی خصوصی ربات بفرست. دانلود به‌صورت تک‌موردی انجام می‌شود (پلی‌لیست به‌طور پیش‌فرض دانلود نمی‌شود). برای ادغام بهترین کیفیت صدا و تصویر، نصب `ffmpeg` لازم است (نصب‌کننده آن را نصب می‌کند). سایت‌های دارای محدودیت حساب، DRM، کپچا یا محدودیت جغرافیایی ممکن است نیازمند کوکی/تنظیمات اضافی باشند؛ تضمین دانلود همه URLها ممکن نیست.
